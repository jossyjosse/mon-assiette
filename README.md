# Mon Assiette

Petite appli web pour iPhone : menus de la semaine (35 recettes), liste de courses, suivi du poids, des pas et de l'activité.

- Tout fonctionne dans le navigateur, sans compte ni serveur : les données restent sur le téléphone.
- À ajouter à l'écran d'accueil depuis Safari : Partager, puis « Sur l'écran d'accueil ».
- Repères : Santé publique France (Manger Bouger), EFSA, OMS.
